# GoHighLevel Beginner Academy

An interactive beginner learning site for practicing common GoHighLevel concepts with a fictional Luna Nail Studio account.

## What's included

- 18 beginner lessons, including source-to-destination field mapping, pipeline management and workflow automation.
- Expanded mock CRM-style dashboard with contacts, conversations, opportunities/pipelines, pipeline builder, forms, a dedicated Source → Destination Mapping Studio, custom fields, workflow builder, execution logs, calendars, landing page studio, reporting, tasks and an expanded Integrations Lab with service selection, permissions checklist, source-to-destination previews, diagnostics and sync logs.
- Five dedicated mapping lessons cover the full source-to-destination data journey, source-field inspection, Contact vs Opportunity destinations, custom fields, required/default/format/dropdown rules, end-to-end testing and troubleshooting.
- Mapping Studio supports multiple source types (website form, Facebook lead form, event QR form), Contact vs Opportunity destinations, field-type compatibility checks, required-field rules, default/formatting notes, custom-field creation, browser-local mapping save and a sample mapped-record preview.
- Client request simulator with realistic support requests.
- **Real Client Scenario Lab with 24 guided troubleshooting playbooks** across funnels/pages, forms/field mapping, CRM/pipelines, workflows/messaging, calendars, integrations/tracking, reporting/handoff, marketing/reputation and account permissions.
- Interactive scenario workbench with inspection/fix/test checklists, search and category filters, practice status, and a sample client update.
- Practice quiz, final client project and browser-based progress features.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Important training note

This is an original educational simulation, not the official GoHighLevel product and not connected to any live GHL account. It does not send real emails/SMS, publish live pages, change client records, spend advertising budget or verify real deliverability. Always practice in an authorized test account before performing paid client work. Get client approval, protect customer data, respect consent/opt-out requirements and document tests before reporting a live issue as fixed.


- Four new integration lessons cover integration fundamentals and permissions, Facebook/website lead-source connections, calendar/email/payment dependencies, and sync-log troubleshooting with client handoff.
- Integrations Lab is a local simulation: it does not connect external accounts, exchange live data, send messages or process payments.


## Scenario Resolution Center (latest update)

The Mock Dashboard now includes a dedicated **Scenario Resolution Center**. It loads every item in the Real Client Scenario Lab and provides category-specific configuration panels, including page/CTA settings, form and field mapping, CRM/pipeline settings, workflow triggers/actions/exit conditions, calendar settings, integration permissions and sync behavior, reporting filters, marketing consent/suppression checks, and account permissions.

Each scenario includes four tabs: Asset & Scope, All Settings, Click Actions, and Verification. The simulated repair action creates a local activity log and the verification checklist records practice completion. These controls do not modify a live GoHighLevel account or send messages.
