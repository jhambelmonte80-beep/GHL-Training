# Beginner GoHighLevel Academy

A beginner-friendly, GitHub Pages training project with lessons, a mock CRM, field-mapping practice, pipeline/workflow exercises, integrations practice, real client scenarios, and a new **GHL Interface Walkthrough**.

## New: GHL Interface Walkthrough

The walkthrough is a clickable educational recreation of common HighLevel work areas. It includes:
- Dashboard orientation
- Contacts table and search
- Opportunities / pipeline board and pipeline setup steps
- Automation / Workflows builder concept, pre-publish checklist, and execution-log examples
- Settings / Custom Fields with Contact vs Opportunity object selection
- Forms and source-to-destination mapping example
- Integrations checklist
- Client troubleshooting scenario
- Links to official HighLevel support documentation

## Important accuracy note

This is **not** the official HighLevel application, a pixel-perfect clone, or a connected account. It uses sample records and local-only actions. HighLevel navigation and available controls can vary by account, permissions, Labs settings, and product updates. Use the official documentation links in the walkthrough and follow the actual UI in an authorized client account.

## Publish with GitHub Pages

1. Upload `index.html` and `README.md` to the root of your repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Open the published Pages URL.
