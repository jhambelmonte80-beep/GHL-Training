# GoHighLevel Academy — GitHub-ready course

A beginner-friendly interactive training website with 11 lessons, plain-language explanations, a fictional CRM dashboard, practice cases, client request scenarios, knowledge checks and a final client simulation.

## New pipeline and workflow training
- Pipeline management lesson covering contacts vs. opportunities, stages, owners, stale leads and follow-up.
- Workflow automation lesson covering triggers, actions, If/Else conditions, delays, enrollment, exit logic and execution logs.
- Interactive Pipeline Board with sample opportunities, stage movement, stage counts and pipeline value.
- Pipeline Builder to add, rename and remove stages, with safeguards for stages that still contain opportunities.
- Workflow Builder to choose a trigger, add/remove actions and run a fictional-contact simulation.
- Workflow list filters and Execution Logs with Success, Skipped and Failed examples.

## Run it
Open `index.html` in a browser. No installation, build tools, API key or paid subscription is needed.

## Publish using GitHub Pages
1. Create a GitHub repository, such as `ghl-academy`.
2. Upload **all files** from this folder. Keep `index.html` at the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click Save.
6. Wait for GitHub Pages to publish. Open the URL shown in the Pages settings.

## Important
This is an original educational simulation inspired by common CRM and funnel concepts. It is **not** the official GoHighLevel interface, does not connect to a live GHL account, and uses fictional demo data. Workflow tests do not send real email or SMS messages. Actual GHL screens and features can change by account and product version. Practice in a permitted test account before changing a client's live setup.

Course completion progress is stored in the browser's local storage. Clearing browser data may reset it.
