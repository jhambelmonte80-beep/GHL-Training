# GHL Academy — Existing Client Practice (120 Missions)

A browser-based local training simulation for practising GoHighLevel-style client support against an already-configured fictional business account (Luna Nail Studio).

## Included
- 120 client request missions (M01–M120)
- Existing contacts, pipelines, opportunities, forms, custom fields, workflows, calendar and integration records
- Editable workspaces for Contacts, Opportunities, Pipelines, Tasks, Forms, Field Mapping, Custom Fields, Landing Pages, Workflows, Execution Logs, Calendars and Integrations
- 20 additional missions focused on source-to-destination mapping, integration troubleshooting and landing-page repairs
- Editable landing-page settings with a live local preview: headline, copy, CTA, destination, SEO title, meta description, color and visible sections
- Integration configuration, add-connection and demo sync-test controls
- Mission-specific expected outcomes and Check My Work assessments
- Browser-local persistence using localStorage; older saved accounts are upgraded without intentionally erasing learner data

## Run
Open `index.html` in a modern browser. No build step, package installation or server is required.

## Suggested workflow
1. Open Client Request Missions.
2. Search or filter for a mission (M101–M120 cover mapping, integrations and landing pages).
3. Read the client brief and expected result.
4. Open the named workspace and inspect existing assets before changing anything.
5. Make the smallest necessary repair and save it.
6. Run a suitable local test (form submission, sync test or landing-page preview).
7. Return to the mission and select Check My Work.

## Important limitations
This is an educational local simulation, not the proprietary GoHighLevel application. It does not connect to a live GHL account, publish a real website, send real email/SMS, authorize third-party services or change client systems. Mission grading evaluates the local demo data and configuration only. Some missions intentionally reuse sample assets so learners can practise different client requests in a controlled account; use Reset demo account to restore the baseline.
