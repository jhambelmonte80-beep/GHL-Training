# Beginner GoHighLevel Academy — Expanded Mission Edition

This is an interactive, local training project for learning common GoHighLevel-style CRM, forms, field mapping, pipelines, opportunities, workflows, calendars, integrations, tasks and troubleshooting processes.

## What is included
- Existing beginner lessons, interface walkthrough and client scenario library.
- Hands-on local sandbox with editable forms, source-to-destination mappings, contacts, pipeline stages, opportunities, workflow triggers/actions, execution logs, calendars, integrations/webhooks and tasks.
- 43 scored client missions covering common support requests.
- Searchable mission library with category filters, hints, per-mission checks, scores and saved progress.
- Local browser persistence using localStorage.

## Run locally / publish on GitHub Pages
Open `index.html` in a browser, or upload `index.html` and this README to the root of a GitHub repository and enable GitHub Pages from the `main` branch and root folder.

## Important limitations
This is an original educational simulation, not the GoHighLevel product. It does not connect to a live GHL account, Facebook, email/SMS providers, payment systems, calendars or external webhooks. All records, actions, test results and grades are local practice data. Menu names and capabilities in a real GHL account can vary by account, permissions and product updates. Never enter real credentials, API keys, payment data or customer personal information into this training site.
