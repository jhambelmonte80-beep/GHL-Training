# GoHighLevel Academy — GitHub-ready course

A beginner-friendly interactive training website with eight lessons, plain-language explanations, a fictional CRM dashboard, practice cases, knowledge checks and a final client simulation.

## Run it
Open `index.html` in a browser. No installation, build tools, API key or paid subscription is needed.

## Publish using GitHub Pages
1. Create a new GitHub repository, such as `ghl-academy`.
2. Upload **all files** from this folder. Keep `index.html` at the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click Save.
6. Wait for GitHub Pages to publish. Open the URL shown in the Pages settings.

## Files
- `index.html` — the complete responsive course and interactive mock dashboard.
- `README.md` — these instructions.

## Important
This is an original educational simulation inspired by common CRM and funnel concepts. It is **not** the official GoHighLevel interface, does not connect to a live GHL account, and uses fictional demo data. Actual GHL screens and features can change by account and product version. Practice in a permitted test account before changing a client's live setup.

Course completion progress is stored in the browser's local storage. Clearing browser data may reset it.
